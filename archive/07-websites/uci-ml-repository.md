# UCI Machine Learning Repository

> 经典机器学习基准数据集与论文资源库

## 它解决什么问题

做 ML 实验缺规范、可复现、有论文背书的基准数据集，网上数据来源混乱。

## 为什么收藏它

UCI 是机器学习最老牌的数据集仓库，Iris、Adult、Wine 等经典数据集都来自这里，做实验/论文复现可靠。

## 我的笔记

- 做分类/回归实验优先来这里找带论文引用的数据集。
- 纯网站资源，github 字段留空、用 website 字段。
- 与 [[red-blob-games]] 同属"经典学习资源站"一类。
