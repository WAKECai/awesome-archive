# labuladong 的算法笔记

> 用"框架思维"讲透 LeetCode 刷题套路的中文算法笔记库

## 它解决什么问题

刷 LeetCode 像背题、换个条件就卡住。缺少一套能"举一反三"的通用解题框架。

## 为什么收藏它

把算法归成有限套路（二叉树、回溯、动态规划、双指针……），每题都落到框架上，配套在线版 labuladong.online，是中文算法学习最流行的一份。

## 我的笔记

- 核心是"框架思维"：先搭模板再套题，而不是记题解。
- 动态规划、回溯、BFS 三套模板最值得先背。
- 与站内 [[archbase]] 的体系结构基础互补：一个偏底层原理、一个偏刷题实战。
