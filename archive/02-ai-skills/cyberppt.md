# CyberPPT

> 生成高密度、可编辑、咨询风格 PowerPoint 的 Codex Skill

## 它解决什么问题

AI 生成的 PPT 常是花哨但信息密度低、不可编辑的"演示稿"，无法满足咨询/汇报场景的高密度、可编辑、风格统一需求。

## 为什么收藏它

一个专门用于生成高密度、可编辑、咨询风格 PPT 的 Agent Skill，支持 SCR 叙事、风格确认和 PPTX 质量检查，把"用 AI 做专业汇报稿"落到可复用流程。

## 我的笔记

- 面向 Codex Skill 生态，逻辑同样可借鉴到其它 Agent 的 PPT 生成流程。
- 关键词：SCR 叙事、风格确认、PPTX 质量检查。
- 与站内 ian-handdrawn-ppt 等 PPT 类技能同属"AI 做演示文稿"路线。
