# identity-skill

> 数字名片 .skill：一键打造专属个人网站

## 它解决什么问题

个人品牌展示需要搭建个人网站，但设计、开发、部署流程繁琐，很多人起步困难。

## 为什么收藏它

一个把"打造数字名片/个人网站"封装成 Skill 的项目，一键生成专属个人网站，降低个人品牌展示的技术门槛。

## 我的笔记

- 适合做个人主页、作品集、简历展示场景。
- 与站内其它"一键生成"类 Agent 技能同属降低创作/展示门槛的路线。
