# OpenSquilla

> Token 高效的开源 AI Agent 运行时

## 它解决什么问题

在相同 token 预算下提升 Agent 的智能密度——用更少的 token 完成更聪明的任务。

## 为什么收藏它

开源（Apache-2.0），支持 skills 技能库、MCP 工具、记忆系统与多会话协作，定位「same budget, higher intelligence density」。

## 我的笔记

运行时与技能生态活跃。可与 [[evox]] 的自进化能力、[[firecrawl]] 等 Agent 工具组合使用。
