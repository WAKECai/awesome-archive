# OpenMinis

> 端侧跑领先模型的免费开源移动 AI Agent（带完整 Linux shell）

## 它解决什么问题

想在 iOS/Android 上让 Claude/GPT/Gemini 拥有真实电脑：完整 Linux shell、浏览器自动化、持久记忆、深度系统集成。

## 为什么收藏它

SwiftUI + Compose 原生实现，内置 iSH/PRoot 沙箱、FFmpeg、Alpine rootfs，可接健康、日历、提醒、联系人、HomeKit、蓝牙等工具，自带 API Key。

## 我的笔记

GPLv3。目前是「给手机插上 Agent OS」最激进的开源方案之一。
