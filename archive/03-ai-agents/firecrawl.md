# Firecrawl

> 把网页转成 LLM 就绪数据的开源 Web 数据平台

## 它解决什么问题

网页抓取后常带大量噪音，不适合直接喂给 LLM。

## 为什么收藏它

提供 search / scrape / crawl / map / batch / 交互式页面操作端点，输出干净 Markdown、结构化 JSON、截图；核心服务可 Docker 自托管，多语言 SDK。

## 我的笔记

RAG/Agent 数据获取的标准件。AGPL-3.0（SDK 部分 MIT）。关联 [[mineru]]（离线文档解析）形成线上线下互补。
