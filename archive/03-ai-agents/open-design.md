# Open Design

> 开源的本地优先「Claude Design 替代」：编码 Agent 当设计引擎

## 它解决什么问题

想要一个让编码 Agent 直接产出设计成品（原型/落地页/仪表盘/PPT/图/视频）为真实文件的本地工具。

## 为什么收藏它

由品牌契约 DESIGN.md 驱动而非画布，主流的 Claude Code/Codex/Cursor 等 CLI 都能当设计引擎，导出 HTML/PDF/PPTX/MP4。

## 我的笔记

与 [[awesome-design-md]] 的 DESIGN.md 规范强相关。做「用代码生成设计」路线的参考实现。
