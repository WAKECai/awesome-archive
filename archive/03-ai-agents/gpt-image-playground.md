# GPT Image Playground

> 基于 OpenAI gpt-image-2 的 Web 图像生成与编辑工作台

## 它解决什么问题

想要一个简洁精美的文生图/参考图/mask 编辑 UI，且数据本地保存。

## 为什么收藏它

批量生成、流式预览、Agent 多轮对话模式、多 provider（OpenAI 兼容 / fal.ai / 自定义 HTTP），历史参数存 IndexedDB 本地。

可部署到 Vercel/CF Workers/Docker/静态托管。做图像生成工具的自托管首选。关联 [[ai-agent-book]] 的多模态章节。
