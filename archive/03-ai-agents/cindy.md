# Cindy

> 开箱即用的本地 AI 智能体客户端（多 harness 混用）

## 它解决什么问题

想自由混用 Claude Code / Codex 等 harness 与不同模型，在一个本地客户端里完成真实工作。

## 为什么收藏它

Electron 桌面 + RN 移动客户端，支持记忆、技能、自动化、MCP 工具接线、插件系统，模型与 harness 可随意组合，后端服务开源(Apache-2.0)。

## 我的笔记

适合重度本地 Agent 用户。注意核心后端服务在私有仓库，开源的是客户端与外壳。
