# 归档目录

这里是所有开源项目归档的存放位置。**Markdown 是唯一真相源**——站点数据由构建脚本从这里解析生成。

## 目录分类

| 路径 | 分类 | 说明 |
|------|------|------|
| `01-foundations/` | 基础/教育 | AI 算法、机器学习教程、学习资源 |
| ... | ... | （按需扩展分类目录） |

## 新增一个归档

1. 新建文件：`archive/<分类>/<项目名slug>.md`
2. 复制 `archive/_template.md` 的骨架
3. 用 **AI Agent 抓取仓库真实数据**填入客观字段，再手动补充你的主观笔记
4. 运行 `npm run build` 即可在站点中看到

> ⚠️ **真相源规则**：所有字段以本 Markdown 为准，不要单独维护 JSON/YAML 数据文件，避免双写不一致。
