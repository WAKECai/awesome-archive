# PlantUML

> 用纯文本描述生成 UML 与各类架构图

## 它解决什么问题

手画 UML / 架构图耗时且难维护，团队协作时图与代码容易脱节。

## 为什么收藏它

用类代码的 PlantUML 语法描述图，自动渲染成 Sequence、Class、Component、时序图等，图随文档走，可交给 AI 生成，也能嵌入 Markdown / CI。

## 我的笔记

- 在线编辑器：https://plantuml-editor.kkeisuke.com/（书签里存的正是它的在线版）。
- 与 [[qmd]] 这类"文本即数据"的思路一致，图和代码一样可版本化、可 diff。
- 适合在架构文档、README、设计评审里用。
