# Overleaf

> 在线协作式 LaTeX 论文与文档编辑器

## 它解决什么问题

本机装 LaTeX 环境麻烦（TeX Live/MacTeX 体积大、配置复杂），多人协作改论文时版本混乱。

## 为什么收藏它

浏览器里直接编译 LaTeX，实时预览、多人协作、版本历史，论文/学术文档工作流标配。社区版可自托管。

## 我的笔记

- 书签里存的是 cn.overleaf.com 的项目页，论文协作就用它。
- 与 [[zotero]] 搭配：Overleaf 写稿 + Zotero 管文献引用，是学术写作者常用组合。
