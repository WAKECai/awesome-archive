# Files.md

> 本地优先、极简的 Markdown 笔记应用（数据全在 .md 文件）

## 它解决什么问题

笔记被锁在私有格式/云里，想要全部数据都是普通 .md 文件、低认知负担的工具。

## 为什么收藏它

支持笔记、日记、任务、清单、聊天式速记，可选自托管同步，代码简单到 LLM 能扩展，哲学是本地所有 + 极简。

## 我的笔记

与 Obsidian 的「开放格式」理念相通但更轻。适合当第二大脑的极简替身。
