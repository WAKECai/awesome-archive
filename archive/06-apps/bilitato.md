# Bilitato

> b站 AI 浏览器插件（视频下载/字幕提取/总结/广告识别/向 AI 提问）

## 它解决什么问题

看 b 站视频时，需要下载视频、提取字幕、总结分段、识别广告、向 AI 提问视频内容，这些操作过去要拼多个工具，且无字幕视频难以利用。

## 为什么收藏它

一站式 b 站 AI 浏览器插件：视频/音频下载、字幕提取、总结分段、广告识别、一键验真、向 AI 提问视频内容；支持 Groq 转录无字幕视频、自定义 API 和 Prompt，BYOK 免费使用。

## 我的笔记

- 亮点：能用 Groq 转录无字幕视频，自定义 API/Prompt，自带 API Key 免费使用。
- 适合经常刷 b 站学习/做笔记、想对视频内容提问的场景。
