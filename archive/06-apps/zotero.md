# Zotero

> 免费开源的文献收集、组织、引用与分享工具

## 它解决什么问题

论文/文献一多就乱：收集、标注、生成参考文献、换格式全都靠手工。

## 为什么收藏它

浏览器插件一键抓取网页/PDF 进文献库，配合 Zotero 插件自动生成 BibTeX/Word/LaTeX 引用，中文社区文档完善。

## 我的笔记

- 中文文档：https://zotero-chinese.com/user-guide/（书签里存的 Zotero 百科全书）。
- 与 [[overleaf]] 搭配：Overleaf 写稿 + Zotero 管引用，学术写作工作流。
- 纯桌面应用，非 Web 项目，放进 06-apps 分类。
