# 小语文稿（Moeka）

> 本地优先、简洁流畅的高性能 Markdown 编辑器

## 它解决什么问题

现有 Markdown 编辑器或堆叠功能、或基于 Web 技术导致性能与资源占用不理想。

## 为什么收藏它

自研编辑器内核（Rust + GPUI，GPU 渲染，非 Web 技术），流畅低占用；支持双向链接、表格、上下标、脚注、公式与图表，集成 Agent 终端（@文件/选区与 CLI 聊天）、实时 Git/Diff、多工作区。

## 我的笔记

纯离线本地运行，仅更新时联网；目前只发布 macOS 版（Win/Linux 计划中）。源码未完全开源，GitHub 上是 release 包 + issue 仓库。
