# FlareMo

> Cloudflare 原生的个人知识管理系统（Memos 兼容 API）

## 它解决什么问题

个人知识碎片（Memos 式短笔记）需要一个自托管、免费额度内可用的聚合管理方案，而主流服务要么收费、要么部署复杂。

## 为什么收藏它

一个 Cloudflare 原生的个人知识管理系统，提供 Memos 兼容 API；基于 Cloudflare Workers + D1 + R2，可自托管、几乎零成本，build-in-public 社区关注度不错。

## 我的笔记

- 技术栈看着很轻：Workers + D1 + R2 + React，适合跑在 Cloudflare 免费额度上。
- 与站内 zotero（文献管理）、obsidian-skills（笔记技能）同属"个人知识管理"生态。
- 亮点是 Memos 兼容 API，可无缝接入现有 Memos 客户端/流程。
